# v0.49.17

This patch release improves stopped-store reads, adds OpenCode 2.1.0 support, and fixes search, summarization, event handling, logging and storage cleanup.

## Upgrading

- **No migration.** `context.db` stays at schema 95 and `store.db` at schema 63. Restart OpenCode 1, OpenCode 2, Pi or Oh My Pi after updating.

## Fixed

- Oh My Pi compaction markers now retain a resolvable history boundary, verify writes and avoid duplicate host summaries (issue 748, thanks @Qiiks).
- Doctor can inspect a fully stopped SQLite store without changing its contents.
- OpenCode 2.1.0 native replay metadata and checkpoints are supported. Once OpenCode 2.1.0 compacts a session, OpenCode 2.0.x can't open it again.
- Automatic search hints now wait for embeddings only within a latency budget, preserve real relevance scores, exclude the live tail and show readable matched fragments (issue 743, thanks @null-axiom).
- Summarizer runs on OpenCode 2 and Pi cost less: a first attempt now writes only the system prompt to the prompt cache, because the rest of each summarizer request changes every run and was written but never read back (issue 744, thanks @null-axiom).
- The OpenCode 2 event loop keeps processing events after a handler error, and a deleted-session sweep recovers missed cleanup (issue 745, thanks @null-axiom).
- Transform timing logs summarize each pass while retaining individual slow stages; system-prompt changes report element hashes, byte lengths and offsets without logging prompt content (issue 746, thanks @null-axiom).
- Stale project identities are removed only when their directories are definitely gone. Session deletion avoids unnecessary fence locks and removes empty lock directories; RPC startup reaps dead discovery records and shutdown prunes empty discovery directories (issue 746, thanks @null-axiom).
- Background embedding work yields after repeated rate limits, and commit-embedding sweeps stop at their five-minute deadline (issue 746, thanks @null-axiom).
- Non-git projects skip commit probes and log once per parking interval instead of on every maintenance tick (issue 747, thanks @null-axiom). Maintenance ticks also use a label that does not imply a dreamer prefix (issue 746, thanks @null-axiom).
- Long sessions no longer stall for seconds when many queued removals apply at once; queued drops commit in bounded chunks.
