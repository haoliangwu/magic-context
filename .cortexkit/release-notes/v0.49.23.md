# v0.49.23

This patch makes sure Magic Context's background runs on Oh My Pi can only use the tools they are given.

## Upgrading

- Restart Oh My Pi after updating. No database migration is needed.

## Fixed

- On Oh My Pi, Magic Context's background runs (the summarizer, the dreamer and their helpers) are meant to run with no tools, or with a short read-only list. Oh My Pi applied that restriction to its built-in tools only, so tools from extensions you have installed were still offered to those runs and could be called. Each background run now gets exactly its own tool list, and starts no run at all if the restriction can't be applied. Your extensions still load, so provider and sign-in extensions keep working. Pi was not affected.
