# v0.49.20

## Fixed

- OpenCode 2 replays the last good request when its database is busy instead of sending an incomplete context.
- Signed-thinking requests keep their accepted prefix across disabled compaction, mode switches, date rollover after restart, and idle passes.
- Oh My Pi keeps Magic Context's `ctx_*` tools at the top level with their complete descriptions and schemas instead of hiding them behind the `xd://` catalog. Missing `ctx_reduce.drop` arguments show an example range (#756, thanks @TheOrdinaryWow for the report and transcript scan).
- Local embeddings follow each model's declared pooling and normalization, including CLS pooling for BGE models. Memories and git commits re-embed in the background; inactive-session history vectors stay out of semantic search until that session runs `/ctx-embed start` (#753, thanks @LouisLau-art).
- OpenCode 2 caps its saved request copies for side questions so memory use no longer grows with every session opened since the server started (#764, thanks @null-axiom).
- Primary sessions on OpenCode 1, OpenCode 2 and Pi no longer strand queued reductions below force pressure. When only the current user prompt prevents summarization, the next pass may summarize past it once. Otherwise, eligible reductions and cleanup can apply together after 2% reclaim or three held execute passes, provided no summary is running or waiting to render. Token limits, tool-call boundaries and signed-thinking safety remain in force; Rust mode is unchanged.
- Dreamer detects first model activity on OpenCode 2, Pi and Oh My Pi. A completely silent primary with a configured fallback stops after 90 seconds, leaving the remaining task time for the fallback; a primary streaming text, reasoning or tool calls keeps its full timeout.
- Semantic auto-search keeps its warm history-vector pool after a hint's one-second deadline and loads only new or changed vectors between turns. Cold vectors no longer block a turn, hints list fragments by relevance, disabled memory skips background memory work, and cancelled `ctx_search` calls stop loading history vectors (#762, thanks @null-axiom for the report and detailed trace).
- OpenCode maintenance sweeps empty recovery-lock folders without removing held locks, resumes previously parked OpenCode 2 orphan sweeps, and retires tag-revision metadata when sessions are permanently deleted. Repeated tag-floor, nudge-evaluation and scheduler-hold diagnostics log on state changes rather than every pass (#746, thanks @null-axiom).

## Changed

- Failed historian and dreamer attempts retain their attempted model and sanitized host error in the Historian tab. Silent-model timeouts record why the attempt stopped, and unknown configured models warn once per process.
- Auto-search deadline diagnostics include per-step timings and attached-hint relevance scores. Background workers shut down without leaving pending requests or resources behind.
