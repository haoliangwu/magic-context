# v0.49.22

This patch keeps Oh My Pi summarizer and dreamer runs working when the conversation they read mentions a file or a URL with `@`.

## Upgrading

## Fixed

- Oh My Pi summarizer and dreamer runs no longer fail or attach files when the transcript they read contains `@` mentions such as `@skill://name` or a file path. Mentions stay literal text, and memories they write keep a plain `@` (#779, thanks @Qiiks).
