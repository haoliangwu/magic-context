General

Plugin behavior · user-level configuration

Enable the magic-context plugin

Allow sessions started exactly from your home directory to use a durable Magic Context project identity. User-level only.

Default: off
language

Optional user-level output language for Magic Context generated prose and guidance, as a 2-letter ISO 639-1 code (e.g. tr, es, de, ja). Leave blank to keep today's behavior.

02

Context window

Defaults first · model exceptions tucked away

cache_ttl.default

Provider prompt-cache lifetime that Magic Context assumes.

How it works

This is Magic Context's deferral gate; it does not change the provider's actual cache lifetime. Use a duration or “never” to keep the prefix warm.

execute_threshold_percentage.default

Context usage percentage (20–90) at which queued drops execute. The safe-window cap is 90%.

execute_threshold_tokens.default

Optional absolute-tokens threshold. When set for a model, overrides the percentage above.

Threshold details

Per-model map only (use 'default' key for a fallback across all unlisted models). Clamped to 90% × context_limit at runtime.

output_reserve

Reserve output tokens from the shared context window. Set 0 to disable the reservation. User-level only.

protected_tokens

Absolute token floor protected from automatic reclaim (4,000–1,000,000). Leave blank to derive it from the model's usable context window. User-level only.

clear_reasoning_age

Reasoning blocks older than N tags are removed whole, only on passes that already rebuild the cache.

compaction.enabled

Let Magic Context manage the context window. Turn this off to keep memory and search features while native compaction (or nothing) owns the window.

Scope

Requires a restart and applies only to user configuration.

Default: on
smart_drops

Experimental: content-aware reclaim of provably-superseded tool output, on top of the existing auto-drop.

What gets reclaimed

Drops superseded todowrite, spent ctx_reduce, and zero-value status outputs, and compresses older edits to a file while keeping the newest. Only acts on passes already busting the cache, so it never causes a cache bust on its own. Off by default while cache stability is being proven.

03

History

Shared across harnesses · model selection lives below

history_budget_percentage

Fraction of context limit reserved for rendered history (0.0–1.0).

historian_timeout_ms

Max wait time for a historian run before timeout.

commit_cluster_trigger.enabled

Fire historian when enough git commit clusters accumulate in the unsummarized conversation tail.

What is a cluster?

A commit cluster is a distinct work phase where the agent made git commits, separated by meaningful user turns.

Default: on
commit_cluster_trigger.min_clusters

Minimum number of commit clusters required to trigger historian

temporal_awareness

Inject elapsed-time markers (e.g. +12m, +3d 4h) between user messages with >5 min gaps.

History rendering details

Add start-date/end-date attributes on rendered compartments. Helps the agent reason about session pacing across long-running and multi-day sessions. On by default.

caveman_text_compression.enabled

Age-tiered compression for long user/assistant text parts.

Compression policy

Active for primary sessions when enabled; subagents are excluded because their context is curated by the parent. Outside the protected tail, oldest 20% of eligible tags get ultra compression, next 20% full, next 20% lite, newest 40% untouched. Always compresses from the original source, so depth shifts are equivalent to compressing the original text directly. Off by default.

caveman_text_compression.min_chars

Text parts shorter than this are left untouched. Range 100–10000, default 500.

04

Memory & search

Recall, retrieval, embeddings, and the mural

memory.enabled

Enable cross-session project memory.

Default: on
memory.injection_budget_tokens

Max tokens for memory injection into session history.

memory.auto_promote

Automatically promote session facts to project memory.

Default: on
memory.retrieval_count_promotion_threshold

Minimum ctx_search retrieval count before a session fact is auto-promoted to project memory.

memory.auto_search.enabled

On each new user message, run ctx_search in the background and append a compact <ctx-search-hint> block of vague fragments when the top hit clears the score threshold.

Hint behavior

Does NOT inject full content — just nudges the agent to run ctx_search for the real result if relevant. Adds one embedding round-trip per new user turn. On by default.

memory.auto_search.score_threshold

Minimum top-hit score for the hint to fire. Higher = fewer but more relevant hints. Range 0.30–0.95.

memory.auto_search.min_prompt_chars

Skip the hint when a user message is shorter than this. Avoids embedding cost on trivial replies. Range 5–500, default 20.

memory.git_commit_indexing.enabled

Index HEAD non-merge commits into ctx_search as a 4th source alongside memories, facts, and message history.

Why index commits?

Useful for agents recalling regressions, prior fixes, and decisions without running git log manually. Off by default.

memory.git_commit_indexing.since_days

Days of HEAD history to index. Older commits are excluded from search. Range 7–3650, default 365.

memory.git_commit_indexing.max_commits

Maximum commits kept per project. Oldest evicted when the cap is reached. Range 100–20000, default 2000.

mural.enabled

Render a deterministic image of project memories that did not fit the context budget.

Embedding · user-level only

embedding.provider

Provider for memory semantic search

embedding.model

Embedding model name (e.g., text-embedding-3-small)

embedding.endpoint

API endpoint URL

embedding.api_key

Authentication key for the embedding API

embedding.local_dtype

ONNX dtype for the local embedding model. The default fp32 keeps today's behavior; quantized choices use less memory.

Uses Xenova/all-MiniLM-L6-v2 locally — no configuration needed

Dreamer schedule

Schedules are global · task model overrides are per-harness

dreamer.disable (inverted)

Controls whether the Dreamer hidden agent is registered. To keep manual /ctx-dream but disable automatic runs, leave enabled and set Schedule to empty.

Default: on
dreamer.inject_docs

Inject ARCHITECTURE.md and STRUCTURE.md into agent context

Tabs change model overrides only. Blank model = this harness's Dreamer model.

Click a schedule to edit cron, task qualifiers, and promotion thresholds. Off means an empty schedule, not a separate enable flag.

07

Prompt surface

Guidance, routing, and tool descriptions

system_prompt_injection.enabled

Inject the magic-context guidance text into the system prompt. On by default. Disabling it stops the guidance block entirely.

Custom agent exclusions

To exclude only specific custom agents, set system_prompt_injection.skip_signatures (a substring list) in the raw editor.

Default: on
prompt_surface.default

Choose the built-in full or light preset.

prompt_surface.models

JSON object of provider/model or provider/* keys to full or light. Leave empty for default routing.

Model routes use the literal provider/model or provider/* form and are case-sensitive; additional slashes in model IDs are preserved.

prompt_surface.guidance_override_path

User-only path to a complete primary guidance section. Relative paths resolve from the user config file.

prompt_surface.tool_descriptions

User-only JSON object keyed by tool ID. Only top-level descriptions change; IDs, parameter schemas, and parameter descriptions remain fixed.

08

Advanced

Storage, harness plumbing, and debugging

sqlite.cache_size_mb

Per-connection page-cache size in MB. Higher reduces disk reads on large databases at the cost of memory. Range 8–1024, default 64.

sqlite.mmap_size_mb

Memory-mapped I/O size in MB. 0 disables mmap. Can speed up large reads on some filesystems. Range 0–4096, default 0.

storage.enforce_private_permissions

Keep Magic Context directories owner-only (0700) and files owner-only (0600). Disable only when a trusted group manages permissions externally.

Default: on
auto_update

Automatically self-update the OpenCode plugin to the latest published version on startup. On by default. (User-config only — project configs cannot change it.)

Default: on
keep_subagents

Retain the child sessions magic-context spawns for its own agents (historian, dreamer, memory migration, key-files, user-memory).

Retention behavior

By default these are deleted on success; enable this to keep their full transcript and token usage for debugging. Kept sessions accumulate until cleared. Off by default.

todowrite.enabled

Register Magic Context's Pi todowrite task-list tool. Disable this if you use another Pi todo extension.

Harness scope

OpenCode has its own built-in todowrite, so this setting only affects Pi. Requires /reload or restart after changing.

todowrite.overlay

Show the persistent todo overlay above the editor while tasks are active. The /todos command and tool remain available when only the overlay is off.

Default: on
pi.subagent_extensions

Optional user-level allowlist for extensions loaded by Pi subagent children. Enter one extension path or package per line.

Design proposal only. Inputs are editable to explore the layout; reload this file to reset. No config writes, model lookups, or network requests.
